# 附录 B：中英词汇对照表

AI 视频工具更听得懂英文。中文想好，英文下单。

## 运镜

| 中文 | English | 一句话 |
|------|---------|--------|
| 推 | dolly in / push in | 往前走，靠近 |
| 拉 | dolly out / pull back | 往后退， reveal 全场 |
| 摇 | pan | 原地左右转头 |
| 移 | truck / track | 横着走 |
| 跟 | follow shot | 跟着人跑 |
| 升降 | crane up / crane down | 上下飞，上帝视角 |
| 环绕 | orbit / arc shot | 绕着主体转圈 |
| 静止 | static camera | 镜头不动 |

## 时长与节奏

| 中文 | English | 一句话 |
|------|---------|--------|
| 2 秒 | 2 seconds | 写进 prompt 的时长 |
| 慢动作 | slow motion | 时间变慢 |
| 快放 | timelapse / fast forward | 时间变快 |
| 钩子 | hook | 前 3 秒留住人 |
| 反转 | twist | 意料之外 |

## 转场

| 中文 | English | 一句话 |
|------|---------|--------|
| 硬切 | cut | 直接切，句号 |
| 淡入/淡出 | fade in / fade out | 黑场过渡，省略号 |
| 闪白 | flash / white flash | 白闪一下，惊叹号 |
| 匹配剪辑 | match cut | 形状/动作接上，双关 |

## 声音

| 中文 | English | 一句话 |
|------|---------|--------|
| 对白 | dialogue | 人说话，第 1 层 |
| 背景音乐 | BGM / background music | 定调子 |
| 音效 | sound effect / SFX | 定真实 |
| 环境音 | ambient noise | 压低，别盖过人声 |
| 静默 | silence | 最贵的，突然没声 |
| 音乐骤停 | music cuts out | 反转前停半拍 |
| 声音设计 | sound design | 写进 prompt 指导后期 |

## 一致性

| 中文 | English | 一句话 |
|------|---------|--------|
| 角色卡 | character card | 固定的外貌描述 |
| 参考图 | reference image | 第一张图，后面照着生成 |
| 角色锁定 | character reference | 同一张脸锁死 |
| 风格 | style | 写实/水彩/电影感，放第一句 |
| 故事功能 | story beat | hook / buildup / twist |
