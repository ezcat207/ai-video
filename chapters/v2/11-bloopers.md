# 第 11 章：翻车现场——12 个问题集中修

**地图定位**：修车章 · 原理 6 + 实战 6。

翻车不是失败，是"学费"。这章把 12 个最常见的问题集中修一遍：每个问题 = 症状 → 原因 → 自查 → 修法 → 预防。

![导演自检表：12 个翻车问题，全部标红叉待修](../images/ch10-bloopers.webp)

## 原理篇（6 个）

**1. 顺序乱了，观众不知道讲什么**
症状：镜头都好看，拼起来不知所云。原因：没写顺序，直接拍。自查：顺序三问答得上来吗？修法：先写顺序（钩子→发展→反转），再拍。预防：开拍前先写顺序，写在分镜表最上面。

**2. 镜头不知道让观众看哪**
症状：画面里东西太多，眼睛没地方落。原因：没定落点。自查：这个镜头，观众看哪？修法：减法——只留一个落点，其他的虚化或移出画面。预防：分镜表里写"落点"。

**3. 什么都拍，15 秒像流水账**
症状：没有减法，全是素材。原因：没删。自查：删掉这个镜头，故事还成立吗？修法：删到删不下去为止。预防：开拍前列"不拍清单"。

**4. BGM 盖过了人声**
症状：听不清故事。原因：声音层级错了。自查：人声响度第 1 吗？修法：BGM 降 3 分贝再听一遍。预防：分镜表里写"声音说明"。

**5. 15 秒讲了个寂寞**
症状：没有变化，像屏保。原因：没写一句话故事。自查：人物从 A 状态到 B 状态了吗？修法：加一个反转。预防：开拍前先写一句话故事。

**6. 视线乱跳，观众出戏**
症状：不知道谁在看谁。原因：视线、方向、动作、光，四条线断了。自查：四条线全过吗？修法：补一个"视线交代"镜头。预防：分镜表里写"锚定词"。

## 实战篇（6 个）

**7. prompt 写不清，AI 瞎猜**
症状：生成结果和想的不一样。原因：感觉词没翻译成镜头语言。自查：prompt 里有"感觉词"吗？修法：感觉 → 镜头语言 → prompt，三步翻译。预防：分镜表里写"感觉词"。

**8. AI 生成的人，第 1 秒和第 10 秒长得不一样**
症状：一致性崩了。原因：锚定词没写全。自查：每个 prompt 的锚定词一样吗？修法：角色卡 + 参考图 + 分段生成。预防：每个 prompt 写同样的锚定词。

**9. 补拍时把 prompt 全改了，AI 又跑偏了**
症状：越补越偏。原因：改多了。自查：只改错的那一句了吗？修法：补拍只改错的那一句。预防：原 prompt 留底，改一句，记一句。

**10. 前 3 秒留不住人**
症状：观众划走了。原因：钩子没立住。自查：最炸的画面在第 1 个镜头吗？修法：把最炸的画面挪到第 1 个镜头，先炸后解释。预防：顺序三问的第一问——"先给看什么"。

**11. 声音配完了，感觉不对**
症状：声音和画面"两张皮"。原因：声音说明没写。自查：每个镜头写"声音说明"了吗？修法：按分镜表的"声音说明"重新配。预防：分镜表里写"声音说明"。

**12. 组装完发现故事讲不圆**
症状：缺一个镜头，故事断了。原因：分镜表没填满。自查：分镜表 7 列全填了吗？修法：补拍缺的那个镜头。预防：表没填满，别开机。
