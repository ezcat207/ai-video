# Appendix B: Chinese–English Glossary

| Chinese （中文） | English | In one line |
|------|---------|--------|
| 顺序 | sequence / order | the order shots line up in |
| 注意力 | attention | where the viewer's eyes go |
| 省略 | omission | don't film everything |
| 连续性 | continuity | one world |
| 镜头语言 | shot language | shot size + movement + duration + sound |
| 景别 | shot size | close-up / medium / wide / establishing |
| 特写 | close-up | magnifies emotion |
| 中景 | medium shot | tells the action |
| 远景 | wide shot | explains relationships |
| 全景 | establishing shot | takes in the whole scene |
| 推近 | push in / dolly in | drags attention to a point |
| 拉远 | pull out / dolly out | releases attention to the whole room |
| 摇 | pan | guides eyes on a tour |
| 移 | truck / tracking | moves with the person |
| 跟 | follow shot | attention sticks to the moving person |
| 静止 | static | camera doesn't move |
| 钩子 | hook | first 3 seconds, the loudest |
| 发展 | buildup | answers "then what?" |
| 反转 | twist | didn't see that coming |
| 闭合 | closure | the viewer's brain fills the middle |
| 关键帧 | key frame | one moment is enough |
| 锚定词 | anchor words | character + scene + light, identical in every prompt |
| 首帧 | first frame | the first frame's picture of a shot |
| 角色卡 | character sheet | picture of what the character looks like (front, side, expressions) |
| 参考图 | reference image | picture of what the scene looks like |
| 补拍 | reshoot / regenerate | change only the wrong line, generate again |
| 分镜表 | shot list / storyboard | the working drawing for the 7 principles |
| 导演手记 | director's notes | one-sentence story + shot list + self-check + blooper log |
| 轴线 | axis / 180-degree line | the line between two people; the camera must not cross it |
| 视线 | eyeline | who's looking at whom |
| 动作匹配 | action match | the action connects |
| 静默 | silence | the most expensive sound effect |
| 音效 | sound effect | footsteps, doors, a meow |
| 对白 | dialogue | the human voice |
