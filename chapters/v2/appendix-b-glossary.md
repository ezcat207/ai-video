# 附录 B：中英词汇对照

| 中文 | English | 一句话 |
|------|---------|--------|
| 顺序 | sequence / order | 镜头排队的次序 |
| 注意力 | attention | 观众的眼睛看哪 |
| 省略 | omission | 不拍所有的事 |
| 连续性 | continuity | 同一个世界 |
| 镜头语言 | shot language | 景别 + 运镜 + 时长 + 声音 |
| 景别 | shot size | 特写 / 中景 / 远景 / 全景 |
| 特写 | close-up | 放大情绪 |
| 中景 | medium shot | 讲动作 |
| 远景 | wide shot | 交代关系 |
| 全景 | establishing shot | 交代全场 |
| 推近 | push in / dolly in | 把注意力拽到一点 |
| 拉远 | pull out / dolly out | 把注意力放出去 |
| 摇 | pan | 带眼睛环顾 |
| 移 | truck / tracking | 跟着人一起动 |
| 跟 | follow shot | 注意力粘在 moving 的人身上 |
| 静止 | static | 镜头不动 |
| 钩子 | hook | 前 3 秒，最炸的 |
| 发展 | buildup | 回答"然后呢" |
| 反转 | twist | 没想到 |
| 闭合 | closure | 观众的脑子补全中间 |
| 关键帧 | key frame | 只需要一个瞬间成立 |
| 锚定词 | anchor words | 角色 + 场景 + 光线，每个 prompt 一样 |
| 首帧 | first frame | 每个镜头的第一帧画面 |
| 角色卡 | character sheet | 角色长相的图（正面、侧面、表情） |
| 参考图 | reference image | 场景长相的图 |
| 补拍 | reshoot / regenerate | 只改错的那一句，重新生成 |
| 分镜表 | shot list / storyboard | 7 条原理的施工图 |
| 导演手记 | director's notes | 一句话故事 + 分镜表 + 自查表 + 翻车记录 |
| 轴线 | axis / 180-degree line | 两个人的连线，镜头不能跳过 |
| 视线 | eyeline | 谁在看谁 |
| 动作匹配 | action match | 动作接得上 |
| 静默 | silence | 最贵的音效 |
| 音效 | sound effect | 脚步声、关门声、猫叫 |
| 对白 | dialogue | 人说话的声音 |
