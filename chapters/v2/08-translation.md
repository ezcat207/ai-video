# 第 8 章：翻译——把感觉变成镜头语言

**地图定位**：原理 7 · 导演 = 翻译。

prompt 写不清，AI 瞎猜。导演的第七工作：把脑子里的"感觉"，翻译成"镜头语言"，再翻译成一句句能指挥 AI 的话。说不清，AI 就瞎猜；说得准，AI 就是最好的剧组。

![少年站在白板前，左边是表情简笔画，右边是分镜小格，中间一个大箭头](../images/ch08-translate.webp)

看这张图：少年站在白板前，左边是一张"紧张"的表情简笔画，右边是三个分镜小格，中间一个大箭头——感觉 → 镜头语言 → 分镜。导演的工作，就是"翻译"：把"我觉得紧张"翻译成"特写 + 推近 + 快切 + 低音"。

## 翻译是什么

**一句话**：感觉 → 镜头语言 → prompt。三步翻译，缺一不可。

**13 岁版**：

- **第 1 步：感觉词**：先说出感觉——"紧张"、"温暖"、"搞笑"、"悬念"。感觉词是"给自己看的"，不用写进 prompt。
- **第 2 步：镜头语言**：把感觉翻译成镜头语言——"紧张" = 特写 + 推近 + 快切 + 低音；"温暖" = 中景 + 慢推 + 暖光；"搞笑" = 中景 + 静止 + 音效。
- **第 3 步：prompt**：把镜头语言写成 prompt——"特写 + 推近 + 2 秒 + 低音说明"。prompt 是"给 AI 看的"，要具体、要数字、要动作。

**感觉词典（常用 6 个）**：
- 紧张 = 特写 + 推近 + 快切 + 低音
- 温暖 = 中景 + 慢推 + 暖光 + 轻音乐
- 搞笑 = 中景 + 静止 + 音效 + 停顿
- 悬念 = 远景 + 慢摇 + 静默 + 突然切
- 感动 = 特写 + 慢推 + 柔光 + 钢琴
- 震撼 = 全景 + 拉远 + 慢动作 + 低音

## 拿 15 秒短视频来说

你的 15 秒，每个镜头先写"感觉词"，再翻译成"镜头语言"，最后写成 prompt。感觉词写在分镜表里，翻译的时候就不会"想说什么，说不出来"。

## Prompt 教学：完整翻译范例

**感觉**："猫要干坏事了，紧张又好笑"

**翻译**：紧张 = 特写 + 推近；好笑 = 中景 + 静止 + 音效

**prompt**：
- 镜头 1：猫的脸部特写，眼睛睁大，镜头缓慢推近，2 秒，感觉：紧张
- 镜头 2：猫悄悄靠近老鼠玩具，镜头静止，音效：爪子落地的"啪"，3 秒，感觉：好笑
- 镜头 3：猫一爪拍飞遥控器，得意地看镜头，3 秒，感觉：反转

**关键**：prompt 里写"感觉"——这是写给你自己的：这个镜头，要的是什么感觉？

## 可复现实验

拿一个感觉词（"紧张"），写两个 prompt：A 版只写"紧张"，B 版写"特写 + 推近 + 2 秒 + 低音"。生成两次，对比结果——翻译这章，一次对比就懂：说得越具体，AI 越听话。

## 翻车预警

- **感觉词翻车**：prompt 里只写"紧张"、"好看"、"电影感"——AI 不懂感觉词，翻译成镜头语言再写。
- **太长翻车**：prompt 写 200 字，AI 抓不住重点——一个镜头，一个感觉，一句 prompt。

## 作业：填空题（明天交）

"我的 15 秒短视频，第____个镜头的感觉是____（感觉词），翻译成镜头语言是____（景别 + 运镜 + 时长 + 声音），prompt 是'____'。"

**示范**："我的 15 秒短视频，第 1 个镜头的感觉是'紧张'，翻译成镜头语言是'特写 + 推近 + 2 秒 + 低音'，prompt 是'猫的脸部特写，眼睛睁大，镜头缓慢推近，2 秒，感觉：紧张'。"

交：填好的句子。
