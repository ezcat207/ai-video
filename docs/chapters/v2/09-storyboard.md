# 第 9 章：分镜——7 条原理装进一张表

**地图定位**：综合章 · 7 条原理的施工图。

分镜没画，剪辑时发现故事讲不圆。导演的施工图，叫"分镜表"：7 条原理，一张表，全装下。拍之前，先把表填满——表填满了，拍的时候就不会"临时想"。

![分镜表：每行一个镜头，每列一条原理](images/ch08-storyboard.webp)

看这张图：分镜表上，每行一个镜头，每列一条原理——顺序、注意力、省略、声音、变化、相信、翻译。填满这张表，7 条原理就"装进"了你的 15 秒。

## 分镜表是什么

**一句话**：分镜表 = 7 条原理的施工图。每行一个镜头，每列一条原理。

**13 岁版**：

| 列 | 问什么 | 填什么 |
|----|--------|--------|
| 顺序 | 第几个？ | 钩子 / 发展 / 反转 |
| 注意力 | 观众看哪？ | 落点 + 景别 + 运镜 |
| 省略 | 删什么？ | 关键帧（只写关键帧） |
| 声音 | 有什么声？ | 对白 / 音效 / 音乐 / 静默 |
| 变化 | 讲什么变化？ | 钩子 / 发展 / 反转 |
| 相信 | 世界塌了吗？ | 锚定词（角色 + 场景 + 光线） |
| 翻译 | 感觉是什么？ | 感觉词 + prompt |

**填表顺序**：先填"顺序"和"变化"（故事骨架），再填"注意力"和"省略"（镜头设计），最后填"声音"、"相信"、"翻译"（执行细节）。

## 拿 15 秒短视频来说

你的 15 秒，分镜表是"开拍许可证"：表没填满，别开机。填满了，生成的时候每个 prompt 都"有据可查"。

## Prompt 教学：分镜行 → prompt

分镜表的一行，就是一个 prompt。把一行的 7 列拼起来，就是"完整 prompt"：

**分镜行**：
- 顺序：第 1 个，钩子
- 注意力：落点 = 猫的眼睛，特写，静止
- 省略：关键帧 = 眼睛睁大
- 声音：静默 1 秒，然后一声猫叫
- 变化：钩子
- 相信：锚定词 = 橘色虎斑猫，绿色眼睛，白色项圈，奶茶店，暖黄灯光
- 翻译：感觉 = 紧张

**完整 prompt**：
- 中文：橘色虎斑猫，绿色眼睛，白色项圈，在奶茶店，暖黄灯光，猫的脸部特写，眼睛睁大，镜头静止，2 秒，感觉：紧张，顺序：第 1 个，钩子
- English: Orange tabby cat, green eyes, white collar, in a milk tea shop, warm yellow light, close-up of the cat's face, eyes widening, static camera, 2 seconds, feeling: tense, order: shot 1, hook

**关键**：分镜表的一行 = 一个 prompt——表填满了，prompt 就"长出来"了。

## 可复现实验

拿你的 15 秒，填一张分镜表（5 行，7 列）。填完再拍——对比"没填表直接拍"的那次，看看：是不是"拍的时候心里有数了"？分镜这章，一次填表就懂。

## 翻车预警

- **空表翻车**：分镜表只填了"画面"，其他列全空——7 列全填，表才"完整"。
- **改表翻车**：拍的时候改主意，表没更新——改主意可以，先改表，再改拍。

## 作业：填空题（明天交）

"我的 15 秒短视频，分镜表有____行。我觉得最难填的一列是____（顺序/注意力/省略/声音/变化/相信/翻译），因为____。"

**示范**："我的 15 秒短视频，分镜表有 5 行。我觉得最难填的一列是'省略'，因为'我总舍不得删镜头'。"

交：填好的句子 + 分镜表（拍照或截图）。
