## 普通 AI 视频工具（通用做法）

| 类型 | 做法 | 适用 |
|------|------|------|
| 文生视频 | 一句话变视频 | 快速出镜头，适合"先试拍" |
| 图生视频 | 一张图变视频 | 更稳，适合"首帧锚定" |
| 图片生成 | 生成首帧图、角色卡、参考图 | 一致性锚定 |
| 剪辑工具 | 组装、配音、配乐、字幕、导出 | 成片组装 |
| 声音工具 | 配音、音效、音乐、静默处理 | 声音层级 |

## 选择原则

1. **先普通，后具体**：先学会通用流程（分镜表 → 首帧 → 生成 → 检查 → 补拍 → 组装），再选具体工具。
2. **一致性优先**：选"支持参考图 + 角色卡"的工具，一致性最稳。
3. **免费额度先试**：先用免费额度跑通一条 15 秒，再决定要不要付费。
4. **不绑模型**：本书不绑任何具体模型——模型会更新，原理不会。
