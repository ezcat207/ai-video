# 引言：先看一条 15 秒的片子

同一条素材，两种命运。

左边：随手拍的 15 秒——镜头晃，话没说完就切了，BGM 盖过了人声。你看了 3 秒，划走了。

右边：导演版的 15 秒——镜头慢慢推近，悬念在第 3 秒抛出来，音乐在反转处停半拍。你看完了，还点了赞。

素材一模一样。差的，是导演脑子里的 7 条原理。

![少年导演拿着场记板，自制片场](images/intro-director.webp)

这本书不教你买设备。你的手机 + 一个普通的 AI 视频工具，就是全部剧组。你要学的，是导演的那套"翻译"：把脑子里的故事，翻译成一个个镜头，再翻译成一句句能指挥 AI 的话。

## 前置假设

这本书假设你已经读完《AI 摄影师：用文字拍照》。8 个决定（光圈/快门/ISO/焦段/角度/构图/光线/色彩）不再重讲——需要时，正文会标：

> 📖 前置知识：《AI 摄影师》第 X 章 → [直达](https://ezcat207.github.io/ai-photography/#c=XX)

## 这本书的规矩

1. **7 条原理到底**：电影 = 时间 + 顺序；镜头 = 注意力；剪辑 = 省略；声音 = 一半的电影；故事 = 变化；连续性 = 相信；导演 = 翻译。每章一条原理。
2. **统一例子**：一条 15 秒的短视频（你的 TikTok/抖音）——每章都在它身上试一遍。
3. **社交货币钩子**：每章回答"这能让我的视频更火吗"。
4. **课堂流程**：概念 → 图上指认 → Prompt 教学 → 实验 → 填空题 → 后路。
5. **每章一份填空题**：交一个镜头或一条分镜，不是写作文。
6. **AI 提示词教学**：每章给 1–2 个 bilingual prompt 范例（中文 + English），直接能用。
7. **工具普通化**：不绑任何具体模型，只讲普通 AI 视频工具的通用做法。

先看片子，再开地图。第 1 章，我们把 7 条原理一次装好。
