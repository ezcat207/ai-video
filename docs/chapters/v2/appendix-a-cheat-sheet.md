# 附录 A：万能句式卡

感觉 → 镜头语言 → prompt 的句式。打印出来，贴在书桌前。

## 感觉 → 镜头语言

| 感觉 | 景别 | 运镜 | 时长 | 声音 |
|------|------|------|------|------|
| 紧张 | 特写 | 推近 | 2 秒 | 低音 |
| 温暖 | 中景 | 慢推 | 3 秒 | 轻音乐 |
| 搞笑 | 中景 | 静止 | 3 秒 | 音效 + 停顿 |
| 悬念 | 远景 | 慢摇 | 3 秒 | 静默 + 突然切 |
| 感动 | 特写 | 慢推 | 3 秒 | 钢琴 |
| 震撼 | 全景 | 拉远 | 3 秒 | 低音 + 慢动作 |

## 镜头语言 → prompt

**中文句式**：
[锚定词：角色 + 场景 + 光线]，[景别]，[动作]，[运镜]，[时长]，感觉：[感觉词]，顺序：第 [几] 个，[钩子/发展/反转]

**English 句式**：
[anchor: character + scene + light], [shot size], [action], [camera movement], [duration], feeling: [feeling], order: shot [n], [hook/buildup/twist]

## 分镜表句式

| 列 | 填法 |
|----|------|
| 顺序 | 第 [几] 个，[钩子/发展/反转] |
| 注意力 | 落点：[什么]，[景别] + [运镜] |
| 省略 | 关键帧：[哪一个瞬间] |
| 声音 | [对白/音效/音乐/静默]：[具体说明] |
| 变化 | [钩子/发展/反转] |
| 相信 | 锚定词：[角色 + 场景 + 光线] |
| 翻译 | 感觉：[感觉词] |

## 补拍句式

原 prompt + **只改错的那一句** + 重新生成。改一句，记一句。
