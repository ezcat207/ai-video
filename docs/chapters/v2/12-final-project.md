# 第 12 章：毕业作品——我的 15 秒短片

**地图定位**：毕业章 · 7 条原理，一条片子。

毕业作品的要求：一条 15 秒的短视频，7 条原理全过，配导演手记。交片子 + 手记，不是写作文。

![红毯首映：少年导演的 15 秒短片在影院大银幕上播放](images/ch11-premiere.webp)

## 毕业作品的要求

**一条 15 秒的短视频**：
- 顺序：钩子 → 发展 → 反转，顺序对
- 注意力：每个镜头一个落点
- 省略：删到删不下去为止
- 声音：对白、音效、音乐、静默，层级对
- 变化：一句话故事，人物从 A 状态到 B 状态
- 相信：视线、方向、动作、光，四条线不断
- 翻译：每个 prompt 都是"感觉 → 镜头语言 → prompt"翻译出来的

**一份导演手记**：
- 一句话故事
- 分镜表（5 行，7 列）
- 原理自查表（7 条原理，逐条打勾）
- 翻车记录（翻过几次车，怎么修的）

## 原理自查表

| 原理 | 检查问题 | 打勾 |
|------|----------|------|
| 顺序 | 顺序三问答得上来吗？ | ☐ |
| 注意力 | 每个镜头一个落点吗？ | ☐ |
| 省略 | 删到删不下去为止了吗？ | ☐ |
| 声音 | 声音层级对吗？ | ☐ |
| 变化 | 人物从 A 状态到 B 状态了吗？ | ☐ |
| 相信 | 四条线全过吗？ | ☐ |
| 翻译 | 每个 prompt 都是翻译出来的吗？ | ☐ |

7 个勾全打上，就是一条能看完的片子。

## 导演手记模板

**一句话故事**：____（谁）想____（干什么），结果____（反转）。

**分镜表**：（贴你的分镜表，5 行，7 列）

**原理自查表**：（贴你的自查表，7 个勾）

**翻车记录**：我翻过车的问题是____，修法是____，预防是____。

**三条评论法**：发给 3 个朋友，问他们 3 个问题——① 前 3 秒留住你了吗 ② 看完知道讲什么了吗 ③ 哪个镜头最记得住。3 条评论，就是"观众反馈"。

## 作业：填空题（毕业交）

"我的毕业作品，一句话故事是'____'。我觉得最难的一条原理是____，因为____。我翻过车的问题是____，修法是____。"

**示范**："我的毕业作品，一句话故事是'一只猫想抓老鼠，结果抓到了遥控器'。我觉得最难的一条原理是'相信'，因为'AI 生成的猫第 1 秒和第 10 秒总像两只猫'。我翻过车的问题是 8 号，修法是'角色卡 + 参考图 + 分段生成'。"

交：15 秒短视频 + 导演手记。

## 后路

毕业不是结束，是开始。7 条原理，你装好了。下一部，你可以拍 30 秒、60 秒、3 分钟——原理一样，只是镜头更多。导演这条路，越走越宽。
