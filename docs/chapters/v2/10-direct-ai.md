# 第 10 章：指挥 AI——从分镜到成片

**地图定位**：实战章 · 从分镜表到成片。

AI 生成的人，第 1 秒和第 10 秒长得不一样。导演的实战工作：指挥 AI，一次一个镜头，生成 → 检查 → 补拍 → 组装。AI 是剧组，导演是你——剧组出问题，导演负责。

## 指挥 AI 是什么

**一句话**：普通 AI 视频工具的通用流程：分镜表 → 一个镜头一个 prompt → 生成 → 检查 → 补拍 → 组装。

**13 岁版**：

- **文生 / 图生**：两种生成方式——"文生视频"是"一句话变视频"，"图生视频"是"一张图变视频"。图生视频更稳：先用 AI 生成一张"首帧"（第一帧的画面），再用这张图生成视频——画面"有锚"，不容易跑偏。
- **首帧是锚**：每个镜头的第一帧，先生成一张"首帧图"，检查通过了，再生成视频。首帧 = "这个镜头的长相"，视频 = "这个长相动起来"。
- **生成 → 检查 → 补拍**：生成完一个镜头，检查 3 件事：① 锚定词对上了吗（角色、场景、光线）② 动作对上了吗 ③ 世界塌了吗。没过，改 prompt 重新生成——这叫"补拍"。
- **组装**：所有镜头生成完，按分镜表的顺序拼起来，配上声音（对白、音效、音乐、静默），加字幕，导出成片。

**两个冷知识**：
1. 一致性实战：角色卡 + 参考图 + 分段生成——"角色卡"是一张"角色长相"的图（正面、侧面、表情），"参考图"是"场景长相"的图，"分段生成"是"一次只生成 2–3 秒，拼起来"。三招一起用，一致性最稳。
2. 补拍是常态：导演不是"一次生成就过"——好片子都是"生成 3 次，选 1 次"。补拍不丢人，补拍是导演的日常。

## 拿 15 秒短视频来说

你的 15 秒，流程是：分镜表 → 每个镜头先生成首帧图 → 检查 → 生成视频 → 检查 → 补拍 → 按顺序组装 → 配声音 → 导出。流程走完，就是一条成片。

## Prompt 教学：补拍 prompt

补拍不是"重新写一遍"——是"只改错的那一句"：

**原 prompt**：橘色虎斑猫，绿色眼睛，白色项圈，在奶茶店，暖黄灯光，猫的脸部特写，眼睛睁大，镜头静止，2 秒

**检查**：眼睛没睁大，像"在睡觉"

**补拍 prompt**：橘色虎斑猫，绿色眼睛，白色项圈，在奶茶店，暖黄灯光，猫的脸部特写，**眼睛突然睁大，瞳孔放大**，镜头静止，2 秒

**关键**：补拍只改"错的那一句"——改多了，AI 又"跑偏"了。

## 可复现实验

拿一个镜头，生成 3 次，选最好的一次。对比 3 次的结果，看看：哪一次"锚定词"最稳？哪一次"动作"最对？指挥 AI 这章，一次"生成 3 次选 1 次"就懂。

## 翻车预警

- **一次过翻车**：生成一次就"将就"——好片子都是"生成 3 次，选 1 次"，将就的片子观众看得出来。
- **全改翻车**：补拍时把 prompt 全改了，AI 又跑偏了——补拍只改错的那一句。

## 作业：填空题（明天交）

"我的 15 秒短视频，第____个镜头补拍了____次，因为____（哪里没过）。补拍时我只改了____（哪一句）。"
