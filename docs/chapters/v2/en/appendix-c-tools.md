## Ordinary AI Video Tools (General Practice)

| Type | What you do | Good for |
|------|-------------|----------|
| Text-to-video | One sentence becomes a video | Fast shot drafts, good for "test shoots" |
| Image-to-video | One picture becomes a video | Steadier, good for "first-frame anchoring" |
| Image generation | First-frame pictures, character sheets, reference images | Consistency anchoring |
| Editing tools | Assembly, voice, music, subtitles, export | Finished-film assembly |
| Sound tools | Voice, effects, music, silence handling | Sound layers |

## How to Choose

1. **General first, specific later**: learn the general flow first (shot list → first frame → generate → check → reshoot → assemble), then pick a specific tool.
2. **Consistency first**: pick tools that "support reference images + character sheets" — the steadiest consistency.
3. **Free credits first**: run one 15-second short on free credits before deciding whether to pay.
4. **Don't lock in a model**: this book locks in no specific model — models update, principles don't.
