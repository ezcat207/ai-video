# Appendix A: Universal Sentence Cards

Sentence patterns for feeling → shot language → prompt. Print it out, stick it above your desk.

## Feeling → Shot Language

| Feeling | Shot size | Movement | Duration | Sound |
|---------|-----------|----------|----------|-------|
| Tense | Close-up | Push in | 2 sec | Low bass |
| Warm | Medium shot | Slow push | 3 sec | Soft music |
| Funny | Medium shot | Static | 3 sec | Effect + pause |
| Suspense | Wide shot | Slow pan | 3 sec | Silence + sudden cut |
| Moving | Close-up | Slow push | 3 sec | Piano |
| Epic | Establishing shot | Pull out | 3 sec | Low bass + slow motion |

## Shot Language → Prompt

**English pattern**:
[anchor: character + scene + light], [shot size], [action], [camera movement], [duration], feeling: [feeling], order: shot [n], [hook/buildup/twist]

**Chinese pattern （中文句式）**:
[锚定词：角色 + 场景 + 光线]，[景别]，[动作]，[运镜]，[时长]，感觉：[感觉词]，顺序：第 [几] 个，[钩子/发展/反转]

## Shot-List Patterns

| Column | Fill it like this |
|--------|-------------------|
| Sequence | Shot [n], [hook/buildup/twist] |
| Attention | Landing spot: [what], [shot size] + [movement] |
| Omission | Key frame: [which moment] |
| Sound | [Dialogue/effect/music/silence]: [specific note] |
| Change | [Hook/buildup/twist] |
| Belief | Anchor words: [character + scene + light] |
| Translation | Feeling: [feeling word] |

## Reshoot Pattern

Original prompt + **change only the line that was wrong** + regenerate. Change one line, log one line.
